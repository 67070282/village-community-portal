## แบ่งการนำเสนอไม่เกิน 3 คน

| สมาชิก | ส่วนที่ควรรับผิดชอบ | ต้องอธิบายได้ด้วยตนเอง |
|---|---|---|
| คนที่ 1: เติมชื่อจริง | ปัญหา ขอบเขต UI/UX และลูกบ้าน | การเรียก API, การกรองข้อมูล, responsive และการออกแบบสถานะ |
| คนที่ 2: เติมชื่อจริง | backend และฐานข้อมูล | FK, JWT/RBAC, transaction, สต็อกและ concurrency |
| คนที่ 3: เติมชื่อจริง | นิติบุคคล Admin รายงานและการทดสอบ | สิทธิ์รายบทบาท, audit logs, tests และข้อจำกัด |

หากมี 1–2 คนให้รวมส่วนตามกำลัง เกณฑ์การนำเสนอเป็นรายบุคคล ทุกคนควรสาธิตและตอบอย่างน้อยหนึ่งเรื่องจากโค้ดที่ตนเข้าใจ ไม่อ้างว่าได้ทำส่วนที่ยังอธิบายไม่ได้

## คำถามที่ควรเตรียม

**ทำไมเลือก MySQL?**
เพราะข้อมูลมีความสัมพันธ์ชัด เช่น ผู้ใช้–โพสต์และอุปกรณ์–การยืม ต้องการ FK และ ACID เพื่อให้สถานะ/จำนวนไม่ขัดแย้ง ตามฐานข้อมูลที่ระบุใน PDF

**SQLite ต่างอย่างไร?**
เป็นตัวเลือกสำหรับ regression tests บนเครื่องที่มี Node ใช้คิวและ BEGIN IMMEDIATE ใน process เดียว ส่วน MySQL ใช้ connection pool และล็อกแถว ไม่ควรนำผลประสิทธิภาพ SQLite ไปสรุปแทน MySQL

**JWT แล้วทำไมมี sessions table?**
JWT ที่ตรวจลายเซ็นอย่างเดียวใช้ต่อได้จนหมดอายุ ตาราง sessions ทำให้ logout หรือเปลี่ยนสิทธิ์เพิกถอน token เดิมได้ โดยตรวจสถานะบัญชีปัจจุบันด้วย

**ทำไมลูกบ้านกดคืนเองไม่ได้?**
เพื่อให้จำนวนในคลังสอดคล้องกับของที่เจ้าหน้าที่รับจริง ลูกบ้านดูวันคืนได้ ส่วนเจ้าหน้าที่เป็นผู้ตรวจรับ

**อุปกรณ์เหลือ 1 ชิ้นแต่มีสองคนกดยืมพร้อมกัน?**
transaction ล็อกแถวอุปกรณ์ คำขอหนึ่งตัดสต็อกก่อน อีกคำขออ่านจำนวนใหม่แล้วได้ 409 ไม่มีจำนวนติดลบ ชุดทดสอบจำลองสอง HTTP requests พร้อมกัน

**ป้องกัน SQL injection / XSS อย่างไร?**
ค่าข้อมูลส่งผ่าน parameter binding; ตัวเลข LIMIT/OFFSET ถูกแปลงและจำกัดก่อนใช้ใน SQL ข้อความแสดงผ่าน escape และมี CSP จำกัด script; ยังไม่เท่ากับผ่าน penetration test เต็มรูปแบบ

**ทำไมมี 55 endpoints?**
เป็นเส้นทางที่ทำงานจริงจาก workflow ไม่ได้เพิ่ม alias เพื่อให้จำนวนเยอะ แยก resource/operations ที่มีสิทธิ์และผลลัพธ์ต่างกัน เอกสารสร้างจาก route definitions ที่เซิร์ฟเวอร์ใช้

**มีอะไรที่ยังไม่เสร็จสำหรับระบบจริง?**
การยืนยันตัวตนว่าเป็นลูกบ้านจริง การกู้รหัสผ่าน การเก็บและลบข้อมูลตามนโยบาย การตรวจไฟล์ และการทดสอบ load/ความปลอดภัยบน deployment จริง
