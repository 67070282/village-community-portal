# ปรับปรุง UX/UI

แนว Swiss: พื้นขาวและเทากลาง, accent Yves Klein Blue #002FA7, ตัวอักษร sans-serif โดยใช้ Helvetica Neue และฟอนต์ไทยของระบบเป็น fallback, เส้นแบ่งบางและการจัดข้อมูลชิดซ้าย

## สิ่งที่เปลี่ยน

- หน้าแรกมีบริการ 01 แจ้งปัญหา / 02 ประกาศของหาย / 03 ยืมอุปกรณ์ อยู่ในพื้นที่เดียวกันและกดใช้งานได้ทันที
- เพิ่มขนาดตัวอักษร ช่องกรอก และพื้นที่กด แยกหัวข้อ เนื้อหา และข้อมูลรองชัดเจน
- ย้ายคำอธิบายโหมดสาธิตไปท้ายหน้า พร้อมคงข้อมูลตัวอย่างและจำนวนจริงจาก API
- แทนแถบความคืบหน้าตายตัวด้วยรายการส่วนตัวที่อ่านจากจำนวนเรื่องและรายการยืมจริง
- แสดงสถานะด้วยข้อความและไอคอน พร้อมรูปแบบเส้น/พื้นหลังที่ต่างกัน ไม่ต้องแยกสีเพียงอย่างเดียว
- ค้นหาแสดงจำนวนผลลัพธ์ และมีปุ่มล้างตัวกรองเมื่อกำลังกรองข้อมูล
- เมนูยุบเมื่อหน้าจอไม่เกิน 1000px เพื่อเพิ่มพื้นที่อ่าน; เปิด/ปิดด้วยปุ่ม พื้นหลัง หรือ Escape
- เมนูมือถือย้ายโฟกัสเข้าด้านในและปิดพื้นที่เบื้องหลังจาก keyboard navigation ขณะเปิด
- ปรับฟอร์มและ dialog ให้ label อ่านง่าย, header ติดอยู่ด้านบน และคืนโฟกัสเมื่อปิด
- การ์ดอุปกรณ์บนมือถือวางภาพลายเส้นด้านซ้ายและรายละเอียด/จำนวน/ปุ่มยืมด้านขวา
- หน้าเข้าสู่ระบบใช้กรอบสีน้ำเงินและภาพ SVG ลายเส้นที่สร้างสำหรับเว็บ ไม่โหลดภาพหรือฟอนต์จาก CDN

## การตรวจสอบ

ตรวจผ่านเบราว์เซอร์ที่ 1440px, 803px และ 390px: Dashboard, ฟอร์มแจ้งเรื่อง, ค้นหา/ล้างตัวกรอง, เมนูมือถือ, อุปกรณ์ และการควบคุมโฟกัส ตรวจหน้า 390px ไม่พบ overflow แนวนอน ตัวอย่างข้อมูลเดิมยังคงอยู่ใน MySQL และการเปลี่ยนนี้ไม่แก้ schema หรือ API

โครงสร้าง Docker + MySQL, API 55 รายการ และการเก็บข้อมูลใน volume คงเดิม ผลทดสอบ API ดู test-results-mysql.txt ส่วนภาพตัวอย่าง UI ล่าสุดดู dashboard-preview.jpg
