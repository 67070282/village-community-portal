Village Community Portal API

REST API v1 · JWT (HS256) · MySQL 8 / SQLite Demo

เอกสารนี้สร้างจาก Route ที่เซิร์ฟเวอร์ใช้งานจริง ดาวน์โหลด OpenAPI 3.0 JSON เพื่อนำเข้า Postman หรือ Swagger Editor ได้

Public: ไม่ต้องล็อกอิน · Resident: สมาชิกทุกบทบาท · Owner: เจ้าของรายการหรือ Admin · Staff: นิติบุคคลและ Admin · Admin: ผู้ดูแลระบบเท่านั้น

ทดลองเรียก API

เข้าสู่ระบบที่หน้าเว็บก่อน ใช้ cookie ของเซสชันปัจจุบัน หรือใส่ Bearer token ด้านล่าง ช่องว่างหมายถึงใช้ cookie ของหน้าเว็บ

POST / PATCH / DELETE จะเปลี่ยนข้อมูลจริงในฐานข้อมูลที่กำลังใช้งาน
